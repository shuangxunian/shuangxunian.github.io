## 需求
my-note分为纯前端，开源；以及my-note-fe，前后端分离，闭源；bug优先修复在my-note上面，如果每次都是将改动复制粘贴到my-note-fe当中，会很麻烦；翻了一下有几条git命令可以满足我的需求

## 命令
在my-note-fe仓库中依次执行以下命令命令：

1. 意为在my-note-fe仓库中添加my-note仓库为远程仓库：
```
git remote add fix https://github.com/shuangxunian/my-note.git
```

2. 拉取my-note仓库的提交记录
```
git fetch fix
```

3. 而后我们可以看见my-note的提交记录，再将提交拉到当前分支：
```
git cherry-pick git-id
```
